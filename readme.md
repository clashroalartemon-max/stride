# Stride — шагомер с друзьями

PWA-шагомер (одностраничное приложение в `index.html`): подсчёт шагов по акселерометру, тренировки с GPS-маршрутом, дневник питания, достижения, магазин наград, босс и питомец — и система друзей на Firebase.

## Технологии

- Чистый HTML/CSS/JS без сборки, всё в одном `index.html`
- Firebase SDK v9 (модульный) через CDN: Anonymous Auth + Cloud Firestore
- Leaflet для карты маршрутов
- localStorage для локального прогресса
- Хостинг на Netlify (статическая публикация корня репозитория)

## Система друзей

- При запуске выполняется анонимный вход (`signInAnonymously`), uid сохраняется.
- **Никнейм** задаётся в «Профиль → Настройки». Перед сохранением проверяется уникальность (без учёта регистра).
- **Найти друга** открывает поиск по нику и отправляет запрос в `friendRequests`.
- **Запросы в друзья** появляются в профиле с кнопками «Принять» и «Отклонить».
- **Рейтинг** показывает шаги друзей за сегодня по убыванию, ваша строка подсвечена.
- Шаги отправляются в Firestore с дебаунсом (8 с, но не реже раза в минуту).

### Структура Firestore

| Коллекция | Поля |
|---|---|
| `users/{uid}` | `uid`, `nickname`, `nicknameLower`, `totalSteps`, `todaySteps`, `todayDate`, `friends[]` |
| `friendRequests/{id}` | `from`, `fromNick`, `to`, `status: 'pending'`, `createdAt` |

### Настройка Firebase (один раз)

1. Firebase Console → Authentication → Sign-in method → включить **Anonymous**.
2. Создать базу Cloud Firestore.
3. Применить правила из `firestore.rules`.
4. Добавить домен сайта в Authentication → Settings → Authorized domains.

## Локальный запуск

Нужен любой статический сервер (сервис-воркер и датчики работают только по http(s)):

```bash
npx serve .
# или
netlify dev
```

Для ПК без датчика включите «Демо-режим» в настройках.
