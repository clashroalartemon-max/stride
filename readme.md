# Stride — шагомер

Одностраничное приложение (`index.html`, без сборки): шагомер, вода, питание, достижения, питомцы и кейсы. Состояние хранится в `localStorage` (объект `S`).

## Персональная норма шагов

`calcRecommendedSteps()` считает дневную цель по возрасту (база 7 500, с 60 лет — 6 000), цели `S.goalType` (похудеть ×1.15, набрать ×0.9), весу (>90 кг +1 000) и полу (мужчины >100 кг +500), с округлением до 500 и границами 3 000–20 000. Пока `S.goalManual === false`, норма применяется к `S.goal` автоматически; кнопки −/+ включают ручной режим, выбор цели в профиле возвращает автоматический.

## Запуск

Откройте `index.html` в браузере или выполните `netlify dev --port 8889`.
